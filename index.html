怎么用这个站

每个组件详情页固定四段，对应四种阅读深度：

① 组件展示
真·运行中的 iframe，可以直接上手操作
② 组件描述
它解决什么问题、关键技术点、踩坑预警
③ 组件代码
完整源码 + 语法高亮 + 一键「在 GitHub 打开」
④ 制作教学
分步拆解原理，同样带 GitHub 原文链接

难度分三档：入门 半小时能读完并改； 进阶 需要理解一两个非直观机制； 高级 涉及物理、状态机或滤镜管线，建议先读教学再看码。

源码不依赖任何构建工具与第三方库，纯 HTML + CSS + 原生 JS。 把单个 .html 存到本地双击打开即可运行；想直接看文件内容，点每张卡片上的「GitHub」。
